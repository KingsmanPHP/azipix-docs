---
title: "Eventos Suportados"
description: "Catálogo completo de eventos enviados pelo motor de webhooks da Azipix."
---

| Evento | Descrição |
| :--- | :--- |
| `charge.pending` | Cobrança gerada e aguardando pagamento do comprador. |
| `charge.paid` | Pagamento confirmado com sucesso pela instituição bancária. |
| `charge.failed` | Transação recusada pela adquirente ou banco emissor. |
| `charge.refunded` | Cobrança estornada total ou parcialmente. |
| `withdrawal.approved` | Solicitação de saque aprovada pela equipe de risco. |
| `withdrawal.paid` | Transferência Pix de saque enviada para a conta bancária do lojista. |
