---
title: "Validação da Assinatura"
description: "Confirme que o webhook veio mesmo da Azipix antes de liberar um pedido."
---

Qualquer pessoa que descubra a sua URL pode enviar um `POST` falso para ela. Por isso, **toda chamada é assinada** e você deve validar a assinatura antes de confiar no conteúdo.

## Cabeçalhos

| Header | Exemplo | Descrição |
| :--- | :--- | :--- |
| `X-Azipix-Event` | `payment.paid` | Nome do evento. |
| `X-Azipix-Timestamp` | `1793833200` | Momento do envio (segundos Unix). |
| `X-Azipix-Signature` | `sha256=5d2c1f...` | HMAC-SHA256 em hexadecimal. |

## Como a assinatura é calculada

```text
assinatura = HMAC_SHA256( segredo, timestamp + "." + corpo_bruto )
```

- `segredo`: o **Segredo** exibido em **Integrações → Webhooks** (começa com `whsec_`).
- `timestamp`: o valor do cabeçalho `X-Azipix-Timestamp`.
- `corpo_bruto`: o corpo da requisição **exatamente como recebido** (bytes/texto original). Não use `JSON.stringify(req.body)`: reformatar o JSON muda a assinatura.

## Passo a passo

1. Leia o corpo bruto da requisição.
2. Calcule o HMAC-SHA256 de `timestamp + "." + corpo_bruto` com o seu segredo.
3. Compare com o valor após `sha256=` usando **comparação em tempo constante**.
4. Recuse se o `timestamp` tiver mais de 5 minutos (proteção contra reenvio).
5. Só então processe o evento.

```javascript Node.js (Express)
import express from "express";
import crypto from "node:crypto";

const app = express();
const SECRET = process.env.AZIPIX_WEBHOOK_SECRET; // whsec_...

// IMPORTANTE: express.raw para ter o corpo bruto
app.post("/webhooks/azipix", express.raw({ type: "application/json" }), (req, res) => {
  const timestamp = req.get("X-Azipix-Timestamp") || "";
  const received = (req.get("X-Azipix-Signature") || "").replace("sha256=", "");

  const expected = crypto
    .createHmac("sha256", SECRET)
    .update(`${timestamp}.${req.body.toString("utf8")}`)
    .digest("hex");

  const ok =
    received.length === expected.length &&
    crypto.timingSafeEqual(Buffer.from(received), Buffer.from(expected)) &&
    Math.abs(Date.now() / 1000 - Number(timestamp)) < 300;

  if (!ok) return res.status(401).send("assinatura inválida");

  const event = JSON.parse(req.body.toString("utf8"));
  if (event.event === "payment.paid") {
    // marque o pedido event.data.id como pago (de forma idempotente)
  }
  res.sendStatus(200);
});
```

```python Python (Flask)
import hmac, hashlib, os, time, json
from flask import Flask, request, abort

app = Flask(__name__)
SECRET = os.environ["AZIPIX_WEBHOOK_SECRET"].encode()

@app.post("/webhooks/azipix")
def azipix_webhook():
    raw = request.get_data()  # corpo bruto (bytes)
    timestamp = request.headers.get("X-Azipix-Timestamp", "")
    received = request.headers.get("X-Azipix-Signature", "").removeprefix("sha256=")

    expected = hmac.new(SECRET, f"{timestamp}.".encode() + raw, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(received, expected) or abs(time.time() - int(timestamp or 0)) > 300:
        abort(401)

    event = json.loads(raw)
    if event["event"] == "payment.paid":
        pass  # marque o pedido event["data"]["id"] como pago
    return "", 200
```

```php PHP
<?php
$secret    = getenv('AZIPIX_WEBHOOK_SECRET');
$raw       = file_get_contents('php://input'); // corpo bruto
$timestamp = $_SERVER['HTTP_X_AZIPIX_TIMESTAMP'] ?? '';
$received  = str_replace('sha256=', '', $_SERVER['HTTP_X_AZIPIX_SIGNATURE'] ?? '');

$expected = hash_hmac('sha256', $timestamp . '.' . $raw, $secret);

if (!hash_equals($expected, $received) || abs(time() - (int)$timestamp) > 300) {
    http_response_code(401);
    exit('assinatura inválida');
}

$event = json_decode($raw, true);
if ($event['event'] === 'payment.paid') {
    // marque o pedido $event['data']['id'] como pago
}
http_response_code(200);
```
