title: "Destinos de saque"
api: "GET /api/withdrawals/destinations"
description: "A chave Banking da conta e as carteiras USDT cadastradas no painel: os únicos destinos aceitos pela API."
---

Escopo exigido: `balance:read`.

Destinos são cadastrados **somente no painel**, pelo titular e com a senha da conta. A API apenas lê e usa o que já existe.

```bash
curl https://api.azipix.com/api/withdrawals/destinations \
  --header 'x-api-key: pk_live_SEU_ID' \
  --header 'x-api-secret: sk_live_SUA_CHAVE_SECRETA'
```

<ResponseExample>
```json 200
{
  "data": {
    "banking": {
      "destination": "banking",
      "keyType": "cnpj",
      "maskedKey": "12.***.***/0001-90",
      "holderName": "Loja Exemplo Ltda"
    },
    "cryptoWallets": [
      {
        "destination": "crypto_wallet",
        "walletId": "6f0a2c1e-8b4d-4c7a-9e21-3d5b7f9a1c02",
        "network": "trc20",
        "networkLabel": "TRON (TRC20)",
        "maskedAddress": "TR7NHq…jLj6t",
        "label": "Binance",
        "createdAt": "2026-11-02T10:15:00.000Z"
      }
    ],
    "usdtEnabled": true

```
</ResponseExample>

<ResponseField name="banking" type="object | null">Chave Banking validada da conta (mascarada), usada por `destination: "banking"`. `null` quando não há chave validada.</ResponseField>
<ResponseField name="cryptoWallets" type="array">Carteiras USDT ativas. Use o `walletId` em `destination: "crypto_wallet"`. Vazia quando o USDT não está liberado.</ResponseField>
<ResponseField name="usdtEnabled" type="boolean">Se o saque em USDT está liberado para a sua conta.</ResponseField>

## Carteiras USDT com as regras da conta

`GET /api/withdrawals/crypto-wallets` (escopo `balance:read`) lista as mesmas carteiras com o que vale para o saque automático:

```json 200
{
  "usdtEnabled": true,
  "maxWallets": 5,
  "cooldownHours": 48,
  "firstToWalletManual": true,
  "networks": [
    { "id": "trc20", "label": "TRON (TRC20)" },
    { "id": "polygon", "label": "Polygon" },
    { "id": "bep20", "label": "BNB Smart Chain (BEP20)" },
    { "id": "erc20", "label": "Ethereum (ERC20)" }
  ],
  "data": [
    {
      "id": "6f0a2c1e-8b4d-4c7a-9e21-3d5b7f9a1c02",
      "network": "trc20",
      "networkLabel": "TRON (TRC20)",
      "maskedAddress": "TR7NHq…jLj6t",
      "label": "Binance",
      "createdAt": "2026-11-02T10:15:00.000Z",
      "ageHours": 220.4,
      "paidBefore": true
    }
  ]
}
```

<ResponseField name="cooldownHours" type="integer">Carência de uma carteira nova: antes dela, saques para essa carteira vão para a revisão da equipe.</ResponseField>
<ResponseField name="firstToWalletManual" type="boolean">Quando `true`, o primeiro saque para cada carteira é sempre conferido pela equipe (`paidBefore: false`).</ResponseField>

<Note>
  Pela API o endereço completo da carteira nunca é exibido, só `maskedAddress`. Cadastrar ou remover carteiras é feito em **Saques → Sacar via USDT**, no painel (cadastro com senha; até 5 carteiras ativas).
</Note>
