Escopo exigido: `balance:read`.

Saques podem ser pedidos no painel (Pix ou **Sacar via USDT**), criados pelas **regras de saque automático** (**Configurações → Saques automáticos**, só Pix) ou solicitados pela API com o escopo `withdrawals:write` (veja [Solicitar saque](/api-reference/balance/request-withdrawal)). Esta rota devolve os 500 mais recentes.

```bash
curl https://api.azipix.com/api/withdrawals \
  --header 'x-api-key: pk_live_SEU_ID' \
  --header 'x-api-secret: sk_live_SUA_CHAVE_SECRETA'
```

## Status de um saque

| `status` | Significado |
| :--- | :--- |
| `analyzing` | Em revisão pela equipe Azipix. |
| `processing` | Sendo enviado automaticamente (Pix pela conta de saída, USDT pela Zendry). |
| `under_review` | Envio automático em conferência (o resultado está sendo confirmado com a adquirente). |
| `approved` | Aprovado, aguardando o envio. |
| `paid` | Pago. `payoutReference` traz o E2E do Pix, o comprovante ou o hash da transação USDT. |
| `rejected` | Recusado. `rejectionReason` explica o motivo e o valor volta ao saldo. |
| `failed` | Não enviado. O valor volta ao saldo. |

## Outros campos

<ResponseField name="destination" type="string">`banking` (chave validada da conta), `pix_key` (chave digitada no painel) ou `crypto_wallet` (USDT para carteira cadastrada).</ResponseField>
<ResponseField name="crypto" type="object">Só em saques USDT: rede, valor em USDT, taxa, cotação e transação. Detalhes em [Consultar saque](/api-reference/balance/withdrawal).</ResponseField>
<ResponseField name="requestedVia" type="string">`panel` (pedido no painel ou por regra) ou `api` (pedido por uma chave de API).</ResponseField>
<ResponseField name="payoutMode" type="string">`manual` (pago ou enviado após revisão da equipe) ou `auto` (enviado automaticamente).</ResponseField>
<ResponseField name="trigger" type="string">Origem: `manual` (pedido avulso, no painel ou pela API), `rule_threshold` ("quando o saldo chegar a R$ X") ou `rule_schedule` ("todo dia às HH:MM").</ResponseField>
