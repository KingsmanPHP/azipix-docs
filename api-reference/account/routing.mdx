---
title: "Métodos e contas liberadas"
api: "GET /api/transactions/routing"
description: "Quais métodos de pagamento estão ativos e quais contas de recebimento processam cada um."
---

Qualquer chave válida pode consultar. Use para:

- saber se Pix e cartão estão liberados e ativos antes de mostrar as opções no seu checkout;
- ver qual conta processa cada método. Cartão é sempre processado pela Zendry: veja [Cartão](/api-reference/charges/create-card).

```bash
curl https://api.azipix.com/api/transactions/routing \
  --header 'x-api-key: pk_live_SEU_ID' \
  --header 'x-api-secret: sk_live_SUA_CHAVE_SECRETA'
```

## Campos

<ResponseField name="routing.allowedPaymentMethods" type="string[]">Métodos liberados pela Azipix para a sua conta.</ResponseField>
<ResponseField name="routing.pixEnabled" type="boolean">Pix ativo em **Integrações**. Desativado, a criação de Pix é recusada.</ResponseField>
<ResponseField name="routing.cardEnabled" type="boolean">Cartão ativo em **Integrações**.</ResponseField>
<ResponseField name="routing.pixProvider" type="string">Conta escolhida para processar Pix (pode vir como `provedor:id`).</ResponseField>
<ResponseField name="routing.cardProvider" type="string">Conta escolhida para processar cartão (pode vir como `provedor:id`).</ResponseField>
<ResponseField name="accounts" type="object[]">Contas de recebimento liberadas para você, com os métodos que cada uma processa.</ResponseField>
<ResponseField name="accounts[].provider" type="string">
  Quem processa. Só contas `zendry` processam cartão.
</ResponseField>
<ResponseField name="accounts[].environment" type="string">`production` ou `sandbox`. Chaves de teste só usam contas `sandbox`.</ResponseField>
<ResponseField name="webhookSecret" type="string">Segredo `whsec_…` para validar a [assinatura dos webhooks](/webhooks/signature) da conta principal.</ResponseField>

<Note>
  Os exemplos de `provider` são ilustrativos: a lista de contas depende do que a Azipix liberou para a sua loja. A escolha de qual conta processa cada método é feita em **Integrações** no painel.
</Note>
