---
title: "Consultar Cobrança"
api: "GET /api/transactions/{id}"
description: "Retorna o status atualizado e detalhes contábeis de uma cobrança específica."
---

### Parâmetros de Rota (Path)

<ParamField path="id" type="string" required>
  O identificador único da transação retornado na criação (ex: `tx_8c72bd1a-9f5b-4321-9988-112233445566`).
</ParamField>

---

### Exemplo de Requisição

```bash cURL
curl --request GET \
  --url https://api.azipix.com/api/transactions/tx_8c72bd1a-9f5b-4321-9988-112233445566 \
  --header 'Authorization: Bearer <SEU_TOKEN>'
```
