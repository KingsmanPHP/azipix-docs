---
title: "Consultar Cobrança"
api: "GET /api/transactions/{id}"
description: "Retorna os dados e o status atual de uma cobrança."
---

<ParamField path="id" type="string" required>
  O `id` retornado na criação (ex.: `tx_8F3A1C9B2D7E4F60`).
</ParamField>

```bash
curl https://api.azipix.com/api/transactions/tx_8F3A1C9B2D7E4F60 \
  --header 'x-api-key: ak_live_SUA_CHAVE'
```

<ResponseExample>
```json 200
{
  "id": "tx_8F3A1C9B2D7E4F60",
  "status": "paid",
  "amountCents": 15000,
  "feeCents": 179,
  "netCents": 14821,
  "paymentMethod": "pix",
  "installments": 1,
  "customerName": "João da Silva",
  "customerEmail": "joao.silva@exemplo.com.br",
  "customerDocument": "52998224725",
  "description": "Pedido #10842",
  "createdAt": "2026-11-04T18:00:00.000Z",
  "paidAt": "2026-11-04T18:01:12.000Z"
}
```

```json 404
{ "error": "Transação não encontrada." }
```
</ResponseExample>

<Tip>
  Use esta rota como **plano B** do webhook: se você não recebeu a notificação de um pedido (servidor fora do ar, por exemplo), consulte o status aqui antes de cancelar o pedido.
</Tip>

Uma cobrança só pode ser consultada pela conta que a criou. Para outras contas, a API responde `403`.
