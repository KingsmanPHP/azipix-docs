---
title: "Listar Cobranças"
api: "GET /api/transactions"
description: "As cobranças da sua conta, das mais recentes para as mais antigas."
---

Escopo exigido: `charges:read`.

<ParamField query="subaccount" type="string">
  Filtra por subconta: o ID de uma subconta sua, `main` (só a conta principal) ou `all` (padrão: tudo). Também pode ir no cabeçalho `X-Subaccount-Id`. Com uma chave vinculada a uma subconta, o filtro é sempre o da chave.
</ParamField>

```bash
curl 'https://api.azipix.com/api/transactions?subaccount=main' \
  --header 'x-api-key: pk_live_SEU_ID' \
  --header 'x-api-secret: sk_live_SUA_CHAVE_SECRETA'
```

Cada item tem os mesmos campos de [Consultar Cobrança](/api-reference/charges/get-charge).

<Note>
  Retorna as **1.000 cobranças mais recentes**. Para conciliar vendas aprovadas sem perder nenhuma, use o [feed de vendas](/api-reference/charges/feed). Para um pedido específico, prefira [Consultar Cobrança](/api-reference/charges/get-charge).
</Note>
