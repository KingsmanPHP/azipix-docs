---
title: "Listar Cobranças"
api: "GET /api/transactions"
description: "Lista as cobranças da sua conta, das mais recentes para as mais antigas."
---

```bash
curl https://api.azipix.com/api/transactions \
  --header 'x-api-key: ak_live_SUA_CHAVE'
```
