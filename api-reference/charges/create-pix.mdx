---
title: "Criar Cobrança Pix"
api: "POST /api/transactions/charge"
description: "Gera um Pix com QR Code e Copia e Cola."
---

### Corpo da requisição

<ParamField body="paymentMethod" type="string" required>
  `"pix"`
</ParamField>

<ParamField body="amountCents" type="integer" required>
  Valor em **centavos**. Mínimo `100` (R$ 1,00), máximo `10000000` (R$ 100.000,00). Em vez dele, você pode enviar `amount` em reais (ex.: `150.00`).
</ParamField>

<ParamField body="customer" type="object" required>
  Dados do pagador.
  <Expandable title="propriedades">
    <ParamField body="name" type="string" required>Nome completo.</ParamField>
    <ParamField body="email" type="string" required>E-mail válido.</ParamField>
    <ParamField body="document" type="string" required>
      CPF ou CNPJ **válido** (com ou sem pontuação). Documentos inválidos são recusados com `400`.
    </ParamField>
    <ParamField body="phone" type="string">Telefone com DDD, ex.: `11987654321`.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="description" type="string">
  Descrição do pedido (até 200 caracteres). Aparece no seu painel e no extrato do adquirente.
</ParamField>

<ParamField header="X-Idempotency-Key" type="string">
  UUID único por cobrança. Repetir a mesma chave devolve a cobrança original em vez de criar outra.
</ParamField>

### Requisição

```bash
curl --request POST \
  --url https://api.azipix.com/api/transactions/charge \
  --header 'x-api-key: ak_live_SUA_CHAVE' \
  --header 'Content-Type: application/json' \
  --header 'X-Idempotency-Key: f2b8a71c-34e8-4682-8cbf-9a3e2d6c1b74' \
  --data '{
    "amountCents": 2990,
    "paymentMethod": "pix",
    "description": "Curso Online",
    "customer": {
      "name": "Maria Oliveira",
      "email": "maria@exemplo.com.br",
      "document": "52998224725"
    }
  }'
```

### Ciclo de vida

| `status` | Significado |
| :--- | :--- |
| `pending` | Pix gerado, aguardando pagamento. |
| `paid` | Pago e confirmado com o adquirente. Você recebe `payment.paid`. |
| `failed` | Expirou ou foi cancelado no adquirente. Você recebe `payment.failed`. |
| `refunded` | Estornado. Você recebe `payment.refunded`. |
| `disputed` | O valor pago divergiu do valor cobrado. A venda fica retida para análise. |
