## Ambientes da API

A Azipix disponibiliza dois ambientes distintos:

| Ambiente | Base URL | Finalidade |
| :--- | :--- | :--- |
| **Produção** | `https://api.azipix.com` | Transações bancárias e financeiras reais |
| **Sandbox / Testes** | `https://api.azipix.com/api` (com header `X-Environment: sandbox`) | Homologação de fluxos sem movimentação de fundos |

<Note>
  Todas as requisições para a API devem ser feitas obrigatoriamente através de HTTPS. Requisições em HTTP puro serão recusadas.
</Note>
