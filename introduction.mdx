A API da **Azipix** permite criar cobranças Pix e de cartão de crédito a partir do seu sistema, consultar o status de cada venda e receber notificações automáticas (webhooks) quando um pagamento é confirmado.

<CardGroup cols={2}>
  <Card title="Pix" icon="bolt" href="/api-reference/charges/create-pix">
    Gere um QR Code e o Pix Copia e Cola. A confirmação chega por webhook segundos depois do pagamento.
  </Card>
  <Card title="Cartão de Crédito" icon="credit-card" href="/api-reference/charges/create-card">
    À vista ou parcelado em até 12x, com o cartão tokenizado no navegador do comprador.
  </Card>
  <Card title="Webhooks" icon="bell" href="/webhooks/overview">
    Notificações assinadas com HMAC-SHA256 quando uma venda é paga, recusada ou estornada.
  </Card>
  <Card title="Consulta" icon="magnifying-glass" href="/api-reference/charges/get-charge">
    Consulte o status de qualquer cobrança a qualquer momento.
  </Card>
</CardGroup>

## URL base

Todas as rotas desta documentação usam a URL base:

```text
https://api.azipix.com/api
```

<Note>
  Só aceitamos HTTPS. Faça as chamadas **a partir do seu servidor**, nunca do navegador ou de um app: a chave de API dá acesso à sua conta.
</Note>

## Antes de começar

1. Sua conta precisa estar **aprovada** pelo compliance da Azipix. Enquanto estiver em análise, a API responde `403 AccountNotApproved`.
2. Os métodos de pagamento (Pix e/ou Cartão) precisam estar **liberados** para a sua conta. Confira em **Integrações** no painel.
3. Crie uma chave de API em **Integrações → Chaves de API**.
