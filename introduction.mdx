## URL base

```text
https://api.azipix.com/api
```

Todas as rotas desta documentação são relativas a essa URL. Por exemplo, criar cobrança é `POST https://api.azipix.com/api/transactions/charge`.

<Note>
  Só aceitamos HTTPS. Chame a API **a partir do seu servidor**, nunca do navegador ou de um app: a chave secreta dá acesso à sua conta.
</Note>

## Antes de começar

<Steps>
  <Step title="Conta aprovada">
    Sua conta precisa estar **aprovada** pelo compliance. Enquanto estiver em análise, a API responde `403 AccountNotApproved` nas rotas de cobrança.
  </Step>
  <Step title="Métodos liberados">
    Pix e/ou Cartão precisam estar **liberados** para a sua conta e ativos em **Integrações** no painel. Você confere pela API em [Métodos e contas liberadas](/api-reference/account/routing).
  </Step>
  <Step title="Credenciais">
    Crie um par de credenciais em **Integrações → Chaves de API**. Veja [Autenticação](/authentication).
  </Step>
</Steps>

## O que a API faz e o que fica no painel

| Pela API | Só pelo painel |
| :--- | :--- |
| Criar e consultar cobranças, comprovantes e o feed de vendas | Criar, rotacionar e revogar chaves de API |
| Criar e gerenciar links de pagamento | Configurar saques programados (regras automáticas) |
| Consultar saldo, extrato e saques | Criar e editar subcontas |
| Solicitar saques por Pix (chave Banking) e em USDT (escopo `withdrawals:write`) | Cadastrar a chave Pix e as carteiras USDT que recebem os saques |
| Consultar chargebacks e enviar a defesa | |
