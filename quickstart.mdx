## 1. Obtenha sua Chave de API

Para interagir com a API, obtenha seu **Token de Autenticação** ou **API Key** através do painel:

1. Acesse o painel da [Azipix](https://azipix.com/login).
2. Vá até a seção **Integrações** ou **Configurações**.
3. Copie sua chave de produção.

## 2. Criando uma Cobrança Pix

Envie uma requisição `POST` para `/api/transactions/charge` (ou `/transactions/charge`):

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.azipix.com/api/transactions/charge \
  --header 'Authorization: Bearer SEU_TOKEN_AQUI' \
  --header 'Content-Type: application/json' \
  --header 'X-Idempotency-Key: e82e2f3d-55c3-4d74-b52d-88b17b2f6ef8' \
  --data '{
    "amountCents": 15000,
    "paymentMethod": "pix",
    "description": "Pedido #10842 - Assinatura Mensal",
    "customer": {
      "name": "João da Silva",
      "email": "joao.silva@exemplo.com.br",
      "document": "12345678901",
      "phone": "11987654321"
    }
  }'
```

```javascript Node.js (Fetch)
const response = await fetch("https://api.azipix.com/api/transactions/charge", {
  method: "POST",

    }
  })
});

const data = await response.json();
console.log("Código Pix Copia e Cola:", data.pixCode);
```

```python Python (Requests)
import requests
import uuid

url = "https://api.azipix.com/api/transactions/charge"
headers = {
    "Authorization": "Bearer SEU_TOKEN_AQUI",
    "Content-Type": "application/json",
    "X-Idempotency-Key": str(uuid.uuid4())
}

payload = {
    "amountCents": 15000,
    "paymentMethod": "pix",
    "description": "Pedido #10842 - Assinatura Mensal",
    "customer": {
        "name": "João da Silva",
        "email": "joao.silva@exemplo.com.br",
        "document": "12345678901",
        "phone": "11987654321"
    }
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

```php PHP (cURL)
<?php
$curl = curl_init();

$payload = [
    "amountCents" => 15000,
    "paymentMethod" => "pix",
    "description" => "Pedido #10842",
    "customer" => [
        "name" => "João da Silva",
        "email" => "joao.silva@exemplo.com.br",
        "document" => "12345678901"
    ]
];

curl_setopt_array($curl, [
    CURLOPT_URL => "https://api.azipix.com/api/transactions/charge",
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode($payload),
    CURLOPT_HTTPHEADER => [
        "Authorization: Bearer SEU_TOKEN_AQUI",
        "Content-Type: application/json",
        "X-Idempotency-Key: " . uniqid()
    ],
]);

$response = curl_exec($curl);
curl_close($curl);
echo $response;
```

## 3. Resposta da API

A API responderá com o identificador da transação e os dados do Pix:

```json
{
  "id": "tx_9a8f27bc-40d1-4cb5-8d51-118f9c0e2a33",
  "status": "pending",
  "amountCents": 15000,
  "paymentMethod": "pix",
  "pixCode": "00020126580014br.gov.bcb.pix0136e9a71f00-0000-0000-0000-0000000000005204000053039865406150.005802BR5925AZIPIX PAGAMENTOS LTDA6009SAO PAULO62070503***6304E8A2",
  "pixQrCodeUrl": "https://api.azipix.com/qr/tx_9a8f27bc",
  "createdAt": "2026-11-03T18:00:00.000Z"
}
```

Exiba o `pixCode` para o seu cliente copiar ou gere uma imagem a partir do QR Code. Assim que o pagamento for concluído no banco, você receberá um **Webhook** de confirmação.
