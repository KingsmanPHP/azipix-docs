---

<Steps>
  <Step title="Crie as credenciais">
    No painel, vá em **Integrações → Chaves de API → Nova chave** e copie o ID (`pk_live_…`) e a chave secreta (`sk_live_…`). O segredo só aparece uma vez. Para testar sem dinheiro real, crie uma chave de **teste** (`sk_test_…`): veja [Ambientes e testes](/environments).
  </Step>
  <Step title="Cadastre seu webhook">
    Em **Integrações → Webhooks**, adicione a URL `https://` do seu servidor e copie o **segredo** (`whsec_…`). Veja [como validar a assinatura](/webhooks/signature).
  </Step>
  <Step title="Crie a cobrança">
    Envie um `POST /transactions/charge` do seu servidor, como no exemplo abaixo.
  </Step>
  <Step title="Mostre o Pix ao comprador">
    Exiba o `pixCode` (Copia e Cola) e/ou a imagem `pixQrCode`.
  </Step>
  <Step title="Receba a confirmação">
    Quando o comprador pagar, enviamos o evento `payment.paid` para o seu webhook. Libere o pedido.
  </Step>
</Steps>

## Criando uma cobrança Pix

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.azipix.com/api/transactions/charge \
  --header 'x-api-key: pk_live_SEU_ID' \
  --header 'x-api-secret: sk_live_SUA_CHAVE_SECRETA' \
  --header 'Content-Type: application/json' \
  --header 'X-Idempotency-Key: 6f1c2a90-3b1e-4f0e-9d4a-0b7c5e2f8a11' \
  --data '{
    "amountCents": 15000,
    "paymentMethod": "pix",
    "description": "Pedido #10842",
    "customer": {
      "name": "João da Silva",
      "email": "joao.silva@exemplo.com.br",
      "document": "52998224725",
      "phone": "11987654321"
    }
  }'
```

```javascript Node.js
import crypto from "node:crypto";

const response = await fetch("https://api.azipix.com/api/transactions/charge", {
  method: "POST",
  headers: {
    "x-api-key": process.env.AZIPIX_KEY_ID,        // pk_live_…
    "x-api-secret": process.env.AZIPIX_SECRET_KEY, // sk_live_…
    "Content-Type": "application/json",
    "X-Idempotency-Key": crypto.randomUUID(),
  },
  body: JSON.stringify({
    amountCents: 15000, // R$ 150,00
    paymentMethod: "pix",
    description: "Pedido #10842",
    customer: {
      name: "João da Silva",
      email: "joao.silva@exemplo.com.br",
      document: "52998224725",
      phone: "11987654321",
    },
  }),
});

const charge = await response.json();
if (!response.ok) throw new Error(charge.message || charge.error);
console.log(charge.id, charge.pixCode);
```

```python Python
import os, uuid, requests

response = requests.post(
    "https://api.azipix.com/api/transactions/charge",
    headers={
        "x-api-key": os.environ["AZIPIX_KEY_ID"],         # pk_live_…
        "x-api-secret": os.environ["AZIPIX_SECRET_KEY"],  # sk_live_…
        "X-Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "amountCents": 15000,
        "paymentMethod": "pix",
        "description": "Pedido #10842",
        "customer": {
            "name": "João da Silva",
            "email": "joao.silva@exemplo.com.br",
            "document": "52998224725",
            "phone": "11987654321",
        },
    },
    timeout=30,
)
response.raise_for_status()
charge = response.json()
print(charge["id"], charge["pixCode"])
```

```php PHP
<?php
$payload = [
    "amountCents" => 15000,
    "paymentMethod" => "pix",
    "description" => "Pedido #10842",
    "customer" => [
        "name" => "João da Silva",
        "email" => "joao.silva@exemplo.com.br",
        "document" => "52998224725",
        "phone" => "11987654321",
    ],
];

$ch = curl_init("https://api.azipix.com/api/transactions/charge");
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode($payload),
    CURLOPT_TIMEOUT => 30,
    CURLOPT_HTTPHEADER => [
        "x-api-key: " . getenv("AZIPIX_KEY_ID"),
        "x-api-secret: " . getenv("AZIPIX_SECRET_KEY"),
        "Content-Type: application/json",
        "X-Idempotency-Key: " . bin2hex(random_bytes(16)),
    ],
]);
$charge = json_decode(curl_exec($ch), true);
curl_close($ch);
echo $charge["pixCode"];
```

```json
{
  "id": "tx_8F3A1C9B2D7E4F60",
  "status": "pending",
  "amountCents": 15000,
  "feeCents": 179,
  "netCents": 14821,
  "paymentMethod": "pix",
  "installments": 1,
  "customerName": "João da Silva",
  "customerEmail": "joao.silva@exemplo.com.br",
  "customerDocument": "52998224725",
  "customerPhone": "11987654321",
  "pixCode": "00020101021226...6304ABCD",
  "pixQrCode": "https://api.qrserver.com/v1/create-qr-code/?size=300x300&data=00020101...",
  "description": "Pedido #10842",
  "createdAt": "2026-11-04T18:00:00.000Z"
}
```

<Tip>
  Guarde o `id` junto ao pedido no seu sistema. Ele vem em todos os webhooks e serve para consultar a cobrança em `GET /transactions/{id}`.
</Tip>

<Note>
  `pixQrCode` pode vir como URL de imagem ou como imagem em base64 (`data:image/png;base64,...`). Os dois funcionam direto no atributo `src` de uma tag `<img>`. As tarifas (`feeCents`) dependem do seu plano.
</Note>
